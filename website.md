# PAGE: `/solution` — Solution

**Goal of this page:** Show the problem clearly, then show how MyWorkSpace solves it — step by step.

## The Problem (Why Teams Are Frustrated)

Most companies run on 4–6 separate tools. Here's what that costs them every day:

- **Context switching** — jumping between apps dozens of times a day breaks focus
- **Information silos** — files in one app, conversations in another, tasks in a third
- **Stalled approvals** — documents sit in the wrong tool, so decisions wait
- **Duplicated data** — the same info typed into multiple systems
- **No single source of truth** — leaders can't get one clear picture of what's happening

## The Solution (What MyWorkSpace Does)

MyWorkSpace replaces that patchwork with **one cohesive platform**:

1. **Centralise operations** — all work-related information in one place, one login, one interface
2. **Automate the admin** — invoice reminders, approval routing, and attendance tracking run by themselves
3. **See everything in real time** — leaders get live data to make confident decisions

## Who This Solution Is For

| Role | What they get |
|---|---|
| **Executives & leaders** | Real-time visibility, automatic reports, audit trails |
| **Project managers** | Boards, workloads, approvals, progress tracking |
| **Team members** | Tasks, chat, files, time tracking — no context switching |
| **HR & finance** | Attendance, leave, invoicing, budgets, spend visibility |
| **Clients & contractors** | A dedicated portal tied to their engagement |

## How It Works (Step by Step)

1. **Sign in securely** — Google, GitHub, LinkedIn, or email/password. Your role automatically determines what you see.
2. **Work in one place** — Accept a task, message a colleague, upload a deliverable, submit for approval — all in one screen, never switching tools.
3. **Operate in real time** — Task updates, messages, calendar events, and approvals reach every stakeholder instantly.

## A Real-World Example (Follow One Invoice)

Let's walk through one typical workflow to show how it works:

1. A project manager creates a task: *"Deliver revised floor plan."*
2. The engineer picks up the task and uploads the drawing to the project folder.
3. The file goes through the **approval chain** — engineer's lead approves, then the client approves — with timestamps recorded.
4. On approval, the finance user generates an **invoice** from the project.
5. The system sends the client an **automated payment reminder** if payment is late.
6. The leader checks the dashboard and sees: task done, approval complete, invoice sent, payment pending.

Everything happened in one platform, and every step is traceable.

# PAGE: `/resources/guides` — Guides

**Goal of this page:** Practical, step-by-step playbooks that teach skills — not just features.

## Guide 1 — "From 5 tools to 1: How to migrate your team to MyWorkSpace"

- **Week 1:** Set up your workspace, roles, and invite core team
- **Week 2:** Move active projects and tasks in (don't move old ones — start clean)
- **Week 3:** Switch communication to channels; import key files
- **Week 4:** Turn on invoicing and approvals; retire the old tools one by one
- **Tip:** Keep one "read-only" archive of old files for 60 days, then sunset it

## Guide 2 — "Setting up approval chains that actually get approved"

- Keep chains short (2–3 steps max) — long chains cause delays
- Name each step clearly (e.g., "Lead → Director → Finance")
- Add deadlines to each step so nothing sits forever
- Route by amount or risk: big amounts need Finance, small ones don't

## Guide 3 — "10 ways teams cut admin time with automated invoicing"

1. Use invoice templates with your branding
2. Turn on automated payment reminders (day 1, day 7, day 14)
3. Attach receipts to invoices immediately
4. Link invoices to projects so budget updates itself
5. Let clients view invoices in their portal (fewer "can you resend that?" emails)
6. Use budget alerts before you overspend
7. Review payment history weekly, not monthly
8. Standardise invoice terms across all clients
9. Archive paid invoices with one click
10. Give Finance a dashboard, not a spreadsheet

## Guide 4 — "Balancing workloads across projects: a manager's guide"

- Review the workload report every Monday morning
- Look for people over 80% capacity — reassign before burnout
- Look for people under 40% — give them stretch tasks
- Spread contractors evenly; track their time per project

## Guide 5 — "Running a construction project from RFI to final invoice"

1. Raise the RFI in the project with drawings attached
2. Route it through the approval chain with a deadline
3. Track change orders against the original budget
4. Approve drawings with the AutoCAD plugin — no downloads
5. Generate the final invoice from approved work
6. Archive everything with the full audit trail for disputes

## Guide 6 — "Role-based access: who should see what"

- **Admin:** everything, including settings
- **Manager:** their projects, team workloads, approvals
- **Member:** their tasks, channels, project files
- **HR:** staff records, attendance, leave
- **Finance:** invoices, budgets, receipts
- **Client:** only their own projects and invoices

## Guide 7 — "Onboarding new hires in a single workspace"

1. Create the account and assign the right role
2. Add them to their team channels and projects
3. Assign their first tasks before day one
4. Use a welcome checklist in the workspace
5. Review their first week in the workload report

## Guide 8 — "Reporting that writes itself: dashboards for leaders"

- Pin your 5 most-watched metrics to one dashboard
- Task completion rate, overdue tasks, hours logged, invoiced amount, approval wait time
- Check the dashboard at the same time daily — consistency beats intensity
- Export monthly PDFs for board meetings in one click

# PAGE: `/resources/help` — Help Center

**Goal of this page:** Answer questions fast. Every answer is written for a non-technical reader.

## Frequently Asked Questions

### Account & Login

- **How do I create an account?** Go to the sign-up page and choose Google, GitHub, LinkedIn, or email/password. You'll be in within 2 minutes.
- **How do I invite team members?** Open Workspace Settings → Members → Invite. Send the invite by email or share the invite link. Each person can then sign in with their own account.
- **I forgot my password.** Use the "Forgot password" link on the login screen. We'll email you a reset link.
- **Can I change my role?** Yes — an Admin can change any member's role in Workspace Settings → Members.

### Projects & Tasks

- **How do I create a project?** Click "New Project", give it a name, add teams/staff, and it's ready. You can add tasks immediately.
- **How do I assign a task?** Open the task, click "Assign", and choose a person or team. The person gets a notification.
- **Can I see all overdue tasks?** Yes — the dashboard shows a live "Overdue" list across all your projects.
- **Can a task have more than one person?** Yes, add multiple assignees if the work is shared.

### Files & Approvals

- **How do I share a file with the team?** Upload it to the project's shared folder. Set permissions (view or edit) per file or folder.
- **Can I undo a file change?** Yes — file versioning keeps the history. Open the file → Versions → Restore.
- **How do approval chains work?** A request goes to the first approver; once approved, it moves to the next — until the chain ends. Everyone in the chain sees the full history.
- **Can I skip an approver?** No — but an Admin can edit the chain if it's wrong.

### Calendar & Notifications

- **How do I set a reminder?** Create a calendar event and choose "Remind me" — the platform notifies you at the time you pick.
- **I'm not getting notifications. What now?** Check two things: (1) browser notifications are allowed, (2) in-app notification settings aren't muted. See Troubleshooting below.

### Billing

- **How do I create an invoice?** Open Billing → New Invoice → choose the client and project → items auto-fill from time and tasks. Add extras, preview, send.
- **Can I brand my invoices?** Yes — upload your logo and set colors in Billing → Templates.
- **Are payment reminders automatic?** Yes — you choose the schedule (e.g., day 1, 7, 14 after due date). The system sends them for you.

### Clients & Security

- **Can clients see my internal files?** No. Clients only see their own projects and invoices through the client portal. Permissions are controlled by your team.
- **Is my data backed up?** Yes — data is stored securely with continuous backups and monitored infrastructure.
- **Who can see the audit trail?** Admins and Managers can view audit logs for their area of responsibility.

## Troubleshooting

| Problem | Likely cause | Fix |
|---|---|---|
| Can't sign in | Wrong provider (SSO) | Use the same provider you signed up with; reset password if needed |
| No notifications | Browser blocked them | Allow notifications in browser settings; check in-app settings |
| Calendar shows wrong time | Timezone setting | Update timezone in Profile → Settings |
| File won't upload | Too large | Check file size limit in Docs; contact support if needed |
| Video call won't start | Microphone/camera permission | Allow mic/camera access in browser settings |
| Invite email not received | Spam folder | Check spam; resend from Workspace Settings → Members |

# PAGE: `/resources/api` — API

**Goal of this page:** Let developers extend MyWorkSpace and connect it to their own systems.

## What Can You Do With the API?

- Create tasks and projects automatically (e.g., from a CRM or form)
- Sync invoices to your accounting software
- Pull reports into your own dashboards
- Build custom integrations for your industry
- Subscribe to events (webhooks) and react in real time

## Quick Start (3 Steps)

1. **Get an API key** — Workspace Settings → Integrations → API → Create key
2. **Authenticate** — send `Authorization: Bearer <your-key>` in every request
3. **Make your first call** — `GET /v1/tasks` returns your tasks as JSON

## Authentication

- **API keys** — simple, good for servers and scripts
- **OAuth 2.0** — for building apps that act on behalf of users
- All requests must use HTTPS

## Core Endpoints

| Method | Endpoint | What it does |
|---|---|---|
| GET | `/v1/tasks` | List and filter tasks |
| POST | `/v1/tasks` | Create a task |
| GET | `/v1/projects` | List projects |
| POST | `/v1/projects` | Create a project |
| GET | `/v1/users` | List users in the workspace |
| POST | `/v1/invoices` | Create an invoice |
| GET | `/v1/approvals` | List pending approvals |
| POST | `/v1/approvals/:id/approve` | Approve a request |
| POST | `/v1/approvals/:id/reject` | Reject a request |
| GET | `/v1/files/:id` | Fetch file metadata and download link |
| POST | `/v1/webhooks` | Register a webhook subscription |

## Webhooks (Events)

Subscribe to events and receive them in real time:

| Event | Fires when |
|---|---|
| `task.created` | A task is created |
| `task.completed` | A task is marked done |
| `approval.requested` | A new approval is requested |
| `approval.resolved` | An approval is approved or rejected |
| `invoice.created` | An invoice is created |
| `invoice.paid` | A payment is recorded |
| `user.invited` | A new member is invited |

## Limits & Fair Use

- **Rate limit:** 100 requests per minute per key (scalable on request)
- **Payload size:** up to 5 MB per request
- **Retention:** webhook events are retried for 24 hours on failure

- JavaScript / TypeScript
- Python
- Go
